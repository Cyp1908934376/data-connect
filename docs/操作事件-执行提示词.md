## 任务：在可视化模板系统中新增"操作事件"步骤类型

### 背景

当前可视化模板已有步骤类型: `DATA_SOURCE`(数据源)、`MAPPING`(映射)、`FILTER`(过滤)、`CALL_TEMPLATE`(调用模板)。现需新增 `OPERATION`(操作事件)，作为独立的操作步骤。

### 核心设计

操作事件是一种**内置数据源引用**的独立步骤。添加操作事件时自动关联数据源，根据数据源类型（`DB` vs `API`）动态切换操作表单。

### 流程位置
```
输入事件 → 操作事件* → 映射事件 → 输出事件
```

## 二、后端改动 ✅ 已完成

### 2.1 新建 `OperationEventExecutor.java`

路径: `src/main/java/com/dataconnect/component/impl/OperationEventExecutor.java`

```java
@Component
public class OperationEventExecutor implements ComponentExecutor {
    @Override
    public String getType() { return "OPERATION"; }
    
    @Override
    public DataPacket execute(DataPacket input, Map<String, Object> config, ExecutionContext context) {
        String sourceType = (String) config.get("sourceType");
        if ("DB".equals(sourceType)) return executeDbOp(input, config, context);
        if ("API".equals(sourceType)) return executeApiOp(input, config, context);
        return DataPacket.error("UNKNOWN", "未知数据源类型");
    }
}
```

需要实现的数据库操作方法:
- `executeQuery()` — 替换 `${param}` 占位符后执行 SELECT
- `executeInsert()` — 构建 INSERT SQL，支持 INPUT_PARAM/FIXED_VALUE/AUTO
- `executeUpdate()` — 构建 UPDATE SET ... WHERE SQL
- `executeDelete()` — 构建 DELETE WHERE SQL（安全检查：必须有WHERE）
- `executeDDL()` — 执行 DDL 语句
- `executeCall()` — 调用存储过程

需要实现的接口操作方法:
- `executeApiCall()` — 发送 HTTP 请求
- `executeJsonProcess()` — JSONPath 提取
- `executeFileSave()` / `executeFileRead()` — 文件读写

### 2.2 修改 `VisualTemplateExecutionService.java`

在 `executeEventSteps` 方法中，steps 循环里增加分支:

```java
} else if ("OPERATION".equals(stepType)) {
    currentData = executeOperationStep(step, currentData, context);
}
```

新增方法:
```java
private DataPacket executeOperationStep(Map<String, Object> step, DataPacket input, ExecutionContext context) {
    ComponentExecutor executor = executorFactory.getExecutor("OPERATION");
    return executor.execute(input, step, context);
}
```

## 四、与现有功能的关系

- **DATA_SOURCE 步骤**: 保留，用于独立的"仅查询"场景。操作事件中的 DB_QUERY 可替代它。
- **MAPPING 步骤**: 保留，操作事件的输出仍可经过映射步骤进行字段转换。
- **数据源管理**: 复用 `/datasource/list` 中已有的数据源，操作事件通过 dsId 引用。
