# 操作事件（Operation Event）详细设计文档

## 1. 概述

### 1.1 定位

操作事件是可视化模板流程中的一种**独立步骤类型**，位于输入事件和输出事件之间。它与现有的"数据源事件"不同——操作事件内置数据源引用，并根据数据源类型（数据库/接口）提供差异化的操作能力。

### 1.2 流程位置

```
输入事件 → [数据源事件] → [操作事件*] → [映射事件] → 输出事件
  (固定)    (可选,查询用)   (核心,可多个)   (字段映射)   (固定)
```

### 1.3 核心设计原则

- **内置数据源**：添加操作事件时自动关联数据源，无需单独添加数据源事件
- **类型驱动 UI**：根据数据源类型（DB vs API）动态切换操作表单
- **参数化**：操作参数使用 `${paramName}` 引用输入事件的输入参数
- **可组合**：多个操作事件可串联，前一步的输出可被后一步使用

## 2. 数据库源操作

### 2.1 操作类型

| 操作类型 | type标识 | 说明 | 返回 |
|---------|----------|------|------|
| 查询 | `DB_QUERY` | SELECT 查询，支持参数化 | 结果集 rows |
| 新增 | `DB_INSERT` | INSERT 单条/批量插入 | affectedRows / insertedId |
| 修改 | `DB_UPDATE` | UPDATE 按条件更新 | affectedRows |
| 删除 | `DB_DELETE` | DELETE 按条件删除 | affectedRows |
| DDL | `DB_DDL` | CREATE INDEX / ALTER / TRUNCATE 等 | success/fail |
| 存储过程 | `DB_CALL` | CALL procedure(params) | 结果集 / out参数 |

值来源类型：
- `INPUT_PARAM` — 输入参数 `${paramName}`
- `FIXED_VALUE` — 固定值
- `AUTO` — 自动（NOW(), UUID(), 自增...）
- `PREV_STEP` — 前一步结果字段 `$prev.fieldName`

## 5. 后端实现方案

### 5.1 新增 Executor

```java
@Component
public class OperationEventExecutor implements ComponentExecutor {
    
    @Override
    public String getType() {
        return "OPERATION";
    }
    
    @Override
    public DataPacket execute(DataPacket input, Map<String, Object> config, ExecutionContext context) {
        String sourceType = (String) config.get("sourceType");
        String operationType = (String) config.get("operationType");
        
        if ("DB".equals(sourceType)) {
            return executeDbOperation(input, config, context);
        } else if ("API".equals(sourceType)) {
            return executeApiOperation(input, config, context);
        }
        
        return DataPacket.error("UNKNOWN_SOURCE_TYPE", "未知数据源类型: " + sourceType);
    }
    
    private DataPacket executeDbOperation(DataPacket input, Map<String, Object> config, ExecutionContext context) {
        String operationType = (String) config.get("operationType");
        switch (operationType) {
            case "DB_QUERY":    return executeQuery(input, config, context);
            case "DB_INSERT":   return executeInsert(input, config, context);
            case "DB_UPDATE":   return executeUpdate(input, config, context);
            case "DB_DELETE":   return executeDelete(input, config, context);
            case "DB_DDL":      return executeDDL(input, config, context);
            case "DB_CALL":     return executeCall(input, config, context);
        }
        return DataPacket.error("UNKNOWN_OP", "未知操作: " + operationType);
    }
    
    // ... 各操作的具体实现
}
```

### 5.2 SQL 参数替换

```java
private String replaceParams(String sql, Map<String, Object> params) {
    for (Map.Entry<String, Object> entry : params.entrySet()) {
        String placeholder = "${" + entry.getKey() + "}";
        if (sql.contains(placeholder)) {
            Object value = entry.getValue();
            if (value instanceof Number) {
                sql = sql.replace(placeholder, value.toString());
            } else {
                sql = sql.replace(placeholder, "'" + value.toString().replace("'", "''") + "'");
            }
        }
    }
    return sql;
}
```

### 5.3 INSERT SQL 构建

```java
private String buildInsertSql(Map<String, Object> config, Map<String, Object> params) {
    String tableName = (String) config.get("tableName");
    List<Map<String, String>> fieldMappings = (List<Map<String, String>>) config.get("fieldMappings");
    
    List<String> fields = new ArrayList<>();
    List<String> values = new ArrayList<>();
    
    for (Map<String, String> mapping : fieldMappings) {
        fields.add(mapping.get("field"));
        String valueSource = mapping.get("valueSource");
        String value = mapping.get("value");
        
        if ("AUTO".equals(valueSource)) {
            values.add(resolveAutoValue(value)); // NOW(), UUID(), etc.
        } else if ("INPUT_PARAM".equals(valueSource)) {
            // ${userName} → params["userName"]
            String paramName = value.replace("${", "").replace("}", "");
            Object paramValue = params.get(paramName);
            values.add(formatSqlValue(paramValue));
        } else {
            values.add(formatSqlValue(value));
        }
    }
    
    return String.format("INSERT INTO %s (%s) VALUES (%s)",
            tableName, String.join(", ", fields), String.join(", ", values));
}
```
